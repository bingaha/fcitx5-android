## 一、语音听写（阿里云 ASR）

通过阿里云 DashScope（Model Studio）funasr 协议 WebSocket 做流式语音识别
（模型如 `qwen-audio-3.0-asr-flash-streaming`），16kHz/16bit/mono PCM，100ms 分片。
中间结果替换、整句结果追加（与 VocoType 语义一致）；停止后 final 一到即上屏，
超时（8s）才用最后的 partial 兜底；60s 单次硬上限；中断/取消存草稿。

两种入口：

- **长按空格（hold-to-talk）**：不切换窗口，实时文字进候选框/输入框预编辑下划线，
  松手即发 finish 并上屏。空格键有录音态视觉：放大 + 呼吸脉动 + “● 录音中，松手上屏”。
- **工具栏话筒**：打开录音窗（状态/音量条/实时镜像/停止/取消/草稿条），
  与长按走同一套 composing 预编辑，上屏逻辑一致。

密码框内禁用语音。

### 新增文件

- `app/src/main/java/org/fcitx/fcitx5/android/input/voice/`
  - `DashScopeClient.kt` — funasr 协议 WebSocket 客户端（OkHttp 手写，无阿里 SDK）：
    `connect/sendPcm/sendFinish/finishAndWait/probe`（连接测试只握手不发音频）
  - `VoiceAudioRecorder.kt` — `AudioRecord` 16k 单声道采集，20ms 读、100ms 组包，RMS 音量回调
  - `VoiceSession.kt` — scope 级会话：录音+流式+异步上屏，`finish()` 非阻塞秒回，
    `cancel()` 存草稿，`voice_draft`（SharedPreferences）
  - `VoiceComponent.kt` — 输入法内入口：`startVoiceInput(holdToTalk)`、
    `finishSpaceHold()`（松手上屏）、空格录音态动效
  - `VoiceInputWindow.kt` — 录音窗纯 UI：状态/音量/镜像/停止/取消/草稿填入·丢弃
- `app/src/main/java/org/fcitx/fcitx5/android/input/wm/HoldAwareFrameLayout.kt`
  — 容器层松手监听（键盘视图中途 detach 时手势不丢失，pointer-id 匹配）
- `app/src/main/java/org/fcitx/fcitx5/android/ui/main/settings/behavior/VoiceSettingsFragment.kt`
  — 设置页：开关/话筒按钮/API Key/endpoint/模型/实时预览、麦克风权限申请、连接测试

## 二、删除键上滑：清空光标前全部文字

删除键上滑超过约 36dp 后松手，删除光标前所有文字（含拼音 preedit、选中区）。
点按删一个、长按连删、左右滑移光标/选词保持不变；斜滑优先判上滑。

### 改动文件

- `app/.../input/keyboard/KeyAction.kt` — 新增 `DeleteBeforeCursorAction`
- `app/.../input/keyboard/BaseKeyboard.kt` — 删除键开启 Y 轴滑动识别，
  上滑消费手势（抑制点按），`Up` 时 net-up 即触发删除
- `app/.../input/keyboard/CommonKeyActionListener.kt` — 处理新 Action：reset fcitx + 删光标前
- `app/.../input/FcitxInputMethodService.kt` — 新增 `deleteAllBeforeCursor()`（主线程，
  清 composing→删选中→按实际光标位置删光标前，batch edit 包裹）
